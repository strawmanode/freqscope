# Security maintenance status

FreqScope is no longer maintained. There are no supported versions, and no
security updates are planned. Responses to vulnerability reports and fixes
are not guaranteed.

The code and documentation remain available as a historical project. Anyone
choosing to run, modify, or distribute it is responsible for assessing its
security and dependencies for their own use. Availability of the source or
reference-data snapshot does not imply a security review or ongoing support.

FreqScope accesses third-party aviation services and data sources. Those
services have their own security policies and maintenance arrangements.
See [NOTICE.md](NOTICE.md) for the project's third-party notices and intended-use
limitations.
